# Promptdeck

Promptdeck is a simple keyboard-first native macOS utility for quickly retrieving and copying AI prompts and CLI commands.

It is macOS-native and keyboard-first. Prompts and CLI Commands are separate logical libraries.

> Promptdeck exists to reduce the number of decisions, clicks, and context switches required to retrieve a known prompt or command.

Simplicity and data portability are intentional design goals.
